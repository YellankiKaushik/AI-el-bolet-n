# Configuration reference

`config.py` loads the project-root `.env` as UTF-8 (BOM allowed). Existing process environment values win. Paired outer quotes are removed, comments/invalid keys are skipped, and there is no shell expansion/interpolation. Restart to load changes. Setup never overwrites `.env`; `.env.example` contains safe defaults/placeholders only.

Use `tools/setup_local.py` for random credentials rather than copying placeholder secrets verbatim. Keep config/backups private; don't post them in issues. Relative database paths are resolved against the project root. Linux mode 0600 is requested by private-file tools; Windows deployments need appropriate inherited/explicit ACLs.

## App, storage and authentication

| Variable | Purpose / requiredness | Default / safe example | Security behavior |
|---|---|---|---|
| `APP_ENV` | Optional locally; required production mode for `production.py` | `development`; production: `production` | Unknown modes rejected; `run.py` refuses production |
| `HOST` | Bind address | `127.0.0.1` | Local entry rejects non-loopback; production container may bind its private interface |
| `PORT` | Listener port | `8787` | Don't publish a development listener externally |
| `PUBLIC_URL` | Origin for source-independent app links | Default `http://localhost:PORT`; example `http://localhost:8787` | No path/query/fragment; production requires HTTPS and canonical host/scheme checks |
| `ADMIN_PASSWORD` | Required stable editor credential; required >=16 chars in production | Randomly generated by setup; never use a documented literal | Raw local server otherwise creates a temporary password and prints it; use setup and don't share logs |
| `SESSION_SECRET` | Stable signing secret; required >=32 chars in production | Randomly generated by setup | Missing local value is ephemeral; rotation/restarts invalidate sessions |
| `DATABASE_PATH` | Optional private SQLite location | Project `data/signal_daily.db` | Persistent local filesystem; don't commit DB/WAL or use network shares |
| `DEMO_MODE` | Optional presentation banner | `false`; demo tool sets `true` | Banner alone does not isolate data or disable mail; use `tools/demo.py` for actual isolation |

`Start-Local.ps1` temporarily overrides HOST/PORT/APP_ENV/PUBLIC_URL to the local values above, `ENABLE_LOCAL_GENERATION=true`, and `EMAIL_DELIVERY_ENABLED=false`, then restores its caller's environment when it exits. It preserves `.env`. `SIGNAL_DAILY_PYTHON` optionally selects a working Python executable; otherwise it probes PATH/`py` and a pre-existing development-runtime fallback. It never installs Python.

## Local model

| Variable | Purpose / requiredness | Default | Limits / implications |
|---|---|---|---|
| `OLLAMA_URL` | Local model API origin | `http://127.0.0.1:11434` | Only HTTP(S) loopback/localhost accepted; do not tunnel/expose it |
| `OLLAMA_MODEL` | Exact installed local model identifier | `gemma4:e4b` | Check `/api/tags` or `ollama list`; no auto-download/cloud fallback |
| `OLLAMA_TIMEOUT` | Model request seconds | `240` | Clamped to 5–600; hardware affects latency |
| `ENABLE_LOCAL_GENERATION` | Enable editor generation | Development true; production false | Production startup requires false; use local JSON and authenticated import remotely |

The model request bounds context/output/response size and permits one in-flight generation. The JSON CLI is a local tool and does not use the server route flag to prohibit its own intentional laptop generation. Non-loopback model URLs are still rejected.

## News collection

| Variable | Purpose / requiredness | Default / example | Behavior |
|---|---|---|---|
| `RSS_FEEDS` | Optional operator-controlled source list | Built-in Hugging Face, MIT Technology Review AI, arXiv AI, The Verge AI | Comma-separated `Label\|https://feed`; at most ten feeds; endpoints must be public HTTPS |
| `RSS_LIMIT` | Total retained records per collection | `80` | Clamped 1–200; per-feed parser also limits records |
| `RSS_MAX_AGE_DAYS` | Recency window for dated stories | `14` | Undated records remain undated; invalid/far-future dates excluded; use a positive integer |
| `RSS_RETRIES` | Additional attempts for transient errors | `1` | Clamped 0–2; collection has an overall time budget |
| `RSS_KEYWORDS` | Comma-separated whole-word relevance terms | `ai,artificial intelligence,machine learning,llm,model,agent,neural,robot,transformer` | Controls which source titles/descriptions are retained |

Only bounded UTF-8 RSS/Atom XML without DTD/entities is accepted. Configuration is trusted operator input, not a reader-submitted URL proxy. DNS/redirect checks are defense in depth; production egress controls remain advisable.

## Optional SMTP

| Variable | Purpose / requiredness | Default / safe example | Security behavior |
|---|---|---|---|
| `EMAIL_DELIVERY_ENABLED` | Deliberate opt-in for confirmation and edition mail | False in setup, `run.py`, production; Windows/demo launchers force false | False disables subscription delivery and batch sending even if SMTP credentials exist |
| `SMTP_HOST` | Required with enabled mail | `smtp.example.com` | Hostname only, no URL scheme/whitespace |
| `SMTP_PORT` | TLS SMTP port | `587` | Allowed: 587/2587 STARTTLS or 465/2465 implicit TLS |
| `SMTP_SSL` | Explicit implicit-TLS selection | `false` | 465/2465 select implicit TLS automatically; true conflicts with STARTTLS ports |
| `SMTP_USER` | Username if provider requires login | No default | Must be configured together with password |
| `SMTP_PASSWORD` | Provider credential if login used | No default; private only | Never commit/log; not an ordinary email inbox password unless provider explicitly says so |
| `MAIL_FROM` | Required enabled-mail sender mailbox | `Signal Daily <newsletter@example.com>` | Validate format and configure a provider-verified sender/DNS |
| `DELIVERY_BATCH_SIZE` | Recipients attempted per send action | `25`; production Compose overrides `5` | Clamped 1–100; synchronous work can outlive a client timeout |

Boolean settings accept `true`/`false` case-insensitively. SMTP settings are validated before connection. Supported startup defaults are mail-off; directly importing/running `server.py` bypasses the `.env`/mail-off setup and retains a legacy development mail default, so use the documented entry points. No real SMTP acceptance has been verified. [Provider setup and consent rehearsal](PRODUCTION_RUNBOOK.md#smtp-setup-and-consent-rehearsal).

## Prepared production / Compose settings

| Variable | Purpose / requiredness | Default / safe example | Implication |
|---|---|---|---|
| `TRUSTED_PROXY` | Literal IP allowed to supply client/protocol headers | `127.0.0.1`; Compose `172.30.0.2` | No wildcard/DNS trust, one hop; backend must remain private |
| `PUBLIC_HOST` | Required by Compose/Caddy | `news.example.com` | DNS host only; actual domain/TLS/port reachability must be verified |
| `EDITOR_CIDR` | Caddy operator IP/VPN allowlist | `127.0.0.1/32`; example reserved `203.0.113.10/32` | Default denies remote editors; replace with the actual approved operator range |
| `DATABASE_FILE` | Restored filename inside Compose `/data` | `signal_daily.db` | Lets an operator select a new restored file while preserving the old database |

Compose overrides internal HOST/PORT/DATABASE_PATH/PUBLIC_URL/proxy trust, disables hosted generation, and reads the existing private `.env` for secrets. No environment example creates a public deployment automatically. Read the [production runbook](PRODUCTION_RUNBOOK.md) before using those files.

## Demo and screenshot tools

`tools/demo.py --name acceptance --port 8790 --empty` uses `.tmp/acceptance/demo.db` and its own `credentials.json`, never the real `.env`. Names are restricted, port 8787 is refused, and the seed helper rejects a target outside `.tmp/.../demo.db`. `--empty` avoids seeding; restart does not reset existing edits. SMTP/generation are always disabled.

Optional screenshot capture uses Node's `NODE_PATH` to resolve Playwright/Sharp and `CHROMIUM_EXECUTABLE` to select an installed browser. These are maintainer-tool settings, not application/runtime requirements. [Reproduction](screenshots/README.md).
